Huzentra Technologies is currently focused on **Flutter app development** and modern digital product development.

- Web Development

## Getting Started

### Clone the repository

```bash
git clone https://github.com/hstechsolutions5-svg/Portfolio-Website.git
cd YOUR-REPOSITORY
```

### Add the logo

Place the approved Huzentra Technologies transparent logo at:

```text
assets/images/huzentra-logo.png
```

### Run locally

You can open `index.html` directly in your browser.

For development, using the **Live Server** extension in Visual Studio Code is recommended.

## Customization

### Social Media Links

Update the placeholder social links in:

```text
js/script.js
```

Replace placeholder `href="#"` values with the official Huzentra Technologies profile URLs.

### Business Email

Once the official Huzentra business email is finalized, update it in `contact.html` and any other relevant sections.

### Contact Form

The current contact form is frontend-only and does not send messages.

It can later be connected using:

- Formspree
- EmailJS
- Supabase
- Firebase
- A custom backend/API

## Deployment on GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select:
   - Branch: `main`
   - Folder: `/ (root)`
6. Save the settings.

GitHub will provide a public website URL once deployment is complete.
